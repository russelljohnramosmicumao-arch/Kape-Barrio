KAPE' BAR-RIO POS — VERSION 1

Included:
- Menu organized by category
- 12 / 16 / 22 oz size selection where shown
- Budget / Premium selection where shown
- Cart and automatic totals
- Local order number
- Receipt preview
- Save receipt as PNG
- LocalStorage for the current order/order number
- Service worker + manifest for offline-capable PWA use

IMPORTANT:
For iPad offline/PWA installation, the files must first be served from an HTTPS website.
A free static host such as GitHub Pages can host this project. After opening the HTTPS site in Safari,
use Share -> Add to Home Screen. Once the app has been loaded and cached, it can continue to work offline.

Pricing was transcribed from the supplied menu images. Two-price items are treated as 16 oz and 22 oz,
and premium two-price items are treated as 16 oz and 22 oz, based on the sizing rule supplied in chat.
Please verify the prices before using this as a live POS.
